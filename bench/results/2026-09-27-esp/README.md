# 2026-09-27：experimental-speed-projection 控制向量

该软件包的 `Qwen3.8-Flash-Next-experimental-speed-projection.gguf`（47 个单位方向，每个方向 2,560 维，每层一个），
以 `--control-vector-scaled FILE:1.0 --control-vector-layer-range 4 44 --cvec-mode project --cvec-dir
per-layer` 方式应用：在第 4-44 层之后，每个超连接流 `h -= (h . v) v`。该软件包将其描述为
拒绝方向投影。Q2_0，RTX 5070，固定专家（`--expert-cache 4000 --pcie-frac 0 --adapt-swaps 0`）。

## 内核（`cvec_parity`）

针对双精度参考进行投影和加法（最大误差 5e-7）；关闭开关时，内核的待处理
残差写入与融合超连接读取自身的写入逐位相同，因此已加载但关闭的向量等同于原版引擎。

## 服务（`esp_serve.py`）

- 已加载但关闭开关（`cvec=0`）与不带该向量的引擎相比：前缀后的 65 / 65 个首个 token（验证窗口
  和批量提示路径）以及三次 256-token 生成**逐 token 相同**。
- 开启、关闭、再次开启：相同（该开关会丢弃对话缓存，因此以一种方式计算的内容不会在
  另一种方式中复用）。
- 提示路径的引导方式与逐 token 路径相同：带向量服务时的首个 token 与逐 token 路径的
  教师强制 argmax 在带向量时一致 62 / 65，与原版一致 57 / 65（原版服务：64 / 65 和 57 / 65）。
- 3 次 256-token 生成的解码 tok/s：原版 66.4，开启 76.7 / 81.2。**并非同类比较：**
  开启后模型会写出不同的文本（在代码提示上，它复制了源文本的一大段，提示查找以 91% 的接受率
  起草该段，而原版在 78 个 token 后停止）。在相同 token 上，它慢 0.2-0.4%。
