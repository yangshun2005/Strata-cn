# 2x RX 6900 XT (gfx1030)：辅助 GPU 的专家与 PCIe 份额（2026-10-04）

当第二块 GPU 持有专家（`--expert-cache-device1`、`--remote-expert-opt`）时，验证窗口的 GPU 计划会把辅助 GPU 持有的专家计入该层的未命中，并将其中的一部分——即 PCIe 份额，未命中的 `pcie_frac`——通过 PCIe 转移到主卡上，由主卡计算这些专家，而辅助 GPU 在此期间处于空闲等待状态。该计划在 `RemoteExperts::begin()` 认领其行之前运行，而 `begin()` 只接管计划未处理的行。#854 使该计划将辅助 GPU 的专家视为对等层级的专家：不算未命中，也永远不会进入 PCIe 份额。以下数字是引擎自身针对每个请求的 `STRATA_DECODE_TIMING=1` 报告。

## 测试平台

- 2x AMD Radeon RX 6900 XT 16 GB (gfx1030)，每块通过 CPU 以 PCIe 4.0 x8 连接；无 P2P。引擎的探测测得主机到设备为 14.1 GB/s，并将 `pcie_frac` 设为 0.39（无探测时默认为 0.55）。AMD Ryzen 5 5600X（6 核，AVX2，无 AVX-512；5 个专家池工作线程加主机线程），128 GB DDR4-3200。
- Ubuntu 26.04，内核 7.0.0-38-generic，ROCm 10.0.0（HIP 7.15.26333）。
- 模型：Qwen3.8-Flash-Next GSQ-RCO IQ3_S（2 个分片，`--native`），启用 MTP 草稿层，`--kv int8 --kv-resident 32768 --max-context 131072`。配置见 [strata-helper.json](strata-helper.json)（`/m` 为模型目录，`/work` 为构建目录；`HIP_VISIBLE_DEVICES=1,0` 使 PCI 总线 0f 上的卡成为主卡）：`--expert-cache auto --expert-cache-device1 auto --remote-expert-opt --spec 4 --spec-min-p 0.5`。主卡缓存持有 4,861 个专家（9.26 GiB），辅助 GPU 再持有 8,163 个（15.46 GiB）；共 24,576 个专家。
- 引擎，均使用 `-DSTRATA_ENABLE_HIP=ON -DCMAKE_HIP_ARCHITECTURES=gfx1030 -DSTRATA_PREFILL_MMQ=ON`：
  - *baseline*：`origin/main` 位于 `6f32ec0`（0.1.39），包含 #835（`6add1a7`；#835 仅更改提示路径的 GEMM，不涉及此处测量的解码路径——因此其提示 tok/s 高于下方修复版本）；
  - *baseline, same base*（2026-10-05）：`6f32ec0` 未变；
  - *fix*：`6f32ec0` 加上 #854（`ffca1b0`）。

## 方法

每个测试组使用全新的服务器。两个请求，每个约 5,000 个提示 token（同一文本的两个偏移），"Summarize the document above in about 300 words"，采样（temperature 1.0，top-p 0.95，top-k 20），最多 600 个 token；每个请求使用引擎的 `strata decode timing` 行。衡量指标为每个验证窗口及其各部分所用的毫秒数；tok/s 还取决于采样答案接受多少草稿，波动更大。

"GPU 到达等待"是主机等待 GPU 到达下一层的时间：启用份额时，主卡每个窗口多花 24 毫秒读取并计算每个层-窗口中约 4 个辅助 GPU 也持有的专家（即"PCIe 条目"列），而辅助 GPU 则在等待。使用修复后，份额只保留没有任何 GPU 持有的专家：此处每个层-窗口为 0.06-0.26，且探测份额相对于 `--pcie-frac 0` 没有额外开销，同时略微减少了 CPU 负载（不使用该份额时 CPU 条目从 1.40 增至 1.61）。在修复之前，`--pcie-frac 0` 是绕过该问题的方法。

## 局限性

一台机器、一个模型、每个测试组两个提示；每个测试组运行一次服务器，使用探测份额的修复版本运行两次（每天各一次）。该更改属于主机代码且与后端无关，但仅运行了 HIP 且仅使用了一个辅助 GPU；三个或四个辅助 GPU 会经过相同的循环，但未进行测试。提示路径不使用此计划，不受该更改影响。
