# 社区基准测试 — Thunderbolt eGPU 中的 RTX 3090，64 GB 内存 — 2026-10-06

在同一台机器、同一天、相同设置下对 Qwen3.8-Flash-Next 的两种量化版本进行测试
（仅量化版本不同）。所有提示词 token 均为全新处理：每个请求
都使用唯一的 nonce，因此不会发生前缀缓存复用（所有地方的复用 token 数均为 0）。

## 硬件

- GPU：NVIDIA GeForce RTX 3090，24 GB，**位于 Thunderbolt 3 eGPU 外接扩展坞中**（单 GPU
  配置；系统中的内置 RTX 3070 Laptop 8 GB 虽然存在，但未被 Strata 使用 —
  也测量并否决了 3090+3070 的多 GPU 拆分方案，详见备注）
- CPU：第 11 代 Intel Core i7-11800H（8 核/16 线程，AVX-512）
- 内存：64 GB DDR4
- 存储：NVMe SSD
- 到 GPU 的 PCIe 链路：Thunderbolt 3（约相当于 PCIe x4）
- 运行期间的其他工作负载：仅空闲桌面

## 软件

- 操作系统：Windows 11 Pro 26H2（内部版本 26300.9457）
- Strata：提交 `1678de333d0e0711bc414ad992b640e1a37dd814`（2026-10-02，浅克隆）
- 引擎：预构建的 `strata.exe` 0.1.34（sm_86，CUDA 13.0），NVIDIA 驱动 617.14 WHQL

## 模型

- Qwen3.8-Flash-Next，Strata GSQ-RCO 包
- 测试的量化版本：**IQ2_XS** 和 **IQ3_XXS**
  （`Qwen3.8-Flash-Next-GSQ-RCO-IQ2_XS-0000{1,2}-of-00002.gguf`，IQ3_XXS 命名模式相同）
- 已加载视觉编码器（mmproj BF16），但这些测试中未使用
- MTP 草稿层：开启

## 设置（两种配置完全相同）

- 启动：`START-HERE.bat --setup --yes --family qwen --model <quant> --gpu 1 --vision yes
  --context 262144`（主机 0.0.0.0，已设置 API 密钥 — 本 PR 中任何地方均未包含该密钥）
- 上下文：262144（原生），KV int8，KV 流式开启（KV 缓存位于内存中）
- 校准：对每个模型运行 `START-HERE.bat --calibrate` → 两者均调优为
  `--pcie-frac 0.00, --spec-min-p 0.70`，7 个 CPU 工作进程
- 采样：温度 0

## 工作负载

- 脚本：`bench.py`（本文件夹），每种配置连续运行 3 次
- 预填充测试：生成带有每请求唯一 nonce 的填充文本（以规避前缀
  缓存），三个目标大小；回答上限为 128 个 token（"Reply with exactly: OK"）
- TTFT：流式请求，首个 token 为推理 token（混合思考模型），
  跳过 keep-alive 和空增量；上限约 500 个 token
- 并行：3 个并发短请求（服务器从单个队列中处理它们）
- 大海捞针（正确性）：将一段秘密代码嵌入约 25.7K 个全新 token 的开头，
  在上下文末尾要求其复述；自动验证
- 预热：无专门预热；每种配置的第 1 次运行在模型
  加载后约 2 分钟开始。每次运行的值在 JSON 文件中；下文的范围包含第 1 次运行
- 失败：无（所有请求均完成，无分页，无 OOM）

解码 tok/s 来自服务器报告的每请求计时（预测 token 数 ÷
生成时间），绝不来自生成 token 数 ÷ 总请求时间。解码是在短生成上测量的
（预填充行 42–72 个 token；TTFT 行流式输出约 200–420
个 token，包含推理）。

正确性（大海捞针）：在每次约 25.7K 个全新 token 下找到 6/6（每种配置 3/3）。

并行（仅供参考，未列入表中）：3 个并发客户端由
单个队列处理；3 × 约 200 token 回答的总墙钟时间：13.5–14.2 秒（IQ2_XS），
19.7–23.2 秒（IQ3_XXS）。

内存：IQ2_XS 常驻时，模型使用约 39 GB 内存，约 23 GB 空闲；IQ3_XXS 时，
约 47 GB / 约 16 GB 空闲。VRAM 使用约 23.3 GB / 24 GB（专家缓存约 17 GiB，IQ2_XS）。
